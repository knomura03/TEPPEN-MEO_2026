# 契約プラン運用手順（店舗単位）

最終更新: 2026-02-14

## 目的
- 画面上の「ORG」はすべて **グループ** として扱います。
- 契約プランは **グループ単位ではなく店舗単位** で管理します。
- 内部ユーザー（`ADMIN` / `SUPERVISOR`）が、店舗ごとのプランを即時または予約で切替できる状態を運用します。

## 用語
- **グループ**: `organizations`（データ分離の境界）
- **店舗**: `stores`（実際に運用する単位）
- **店舗契約**: `store_subscriptions`（現在の店舗プラン）
- **店舗プラン予約**: `store_subscription_plan_schedules`（未来日時での切替予約）

## 事前準備
1. 右上の店舗セレクタで対象店舗を選択できること
2. 以下 migration が適用済みであること
   - `supabase/migrations/202602140001_p6_store_subscriptions_and_group_ui_cleanup.sql`
3. 以下 Edge Function がデプロイ済みであること（`--no-verify-jwt`）
   - `admin-billing-plan-upsert`
   - `admin-billing-plan-delete`
   - `admin-store-subscription-set-plan`

## 運用手順

### 1) プランを作成/更新する（内部のみ）
1. サイドバー `契約プラン` を開く
2. `内部: 契約プラン管理` の `プラン作成/更新` を入力
3. `保存` を押す
4. `プラン一覧` に反映されることを確認

### 2) 店舗へ即時割当する（内部のみ）
1. 右上の店舗セレクタで対象店舗を選択
2. `契約プラン` 画面の `店舗へのプラン割当` でプランを選択
3. `反映日時` を空欄のまま `この店舗に割当` を押す
4. `現在の契約プラン` が更新されることを確認

### 3) 店舗へ予約割当する（内部のみ）
1. 手順2と同様に対象店舗を選択
2. `反映日時` に未来日時を入力
3. `予約切替を登録` を押す
4. `予約切替一覧` に表示されることを確認

### 4) プラン削除
- `契約プラン` 画面で削除対象を選択し `選択削除` を実行
- 以下に該当するプランは削除できません
  - `store_subscriptions` で利用中
  - `store_subscription_plan_schedules` で予約済み/適用済み

## よくある質問

### Q. なぜ「グループ」ではなく「店舗」に割り当てるの？
- 同じグループ内でも店舗ごとに運用実態が違うためです。  
  例: 本店は上位プラン、試験店舗はFREE、という割当ができます。

### Q. MANAGERやUSERはプラン変更できますか？
- できません。プラン変更は `ADMIN` / `SUPERVISOR` のみです。

### Q. 店舗作成直後のプランはどうなる？
- `FREE` が自動割当されます（未設定状態は作らない）。
