# TEPPEN MEO：Googleビジネスプロフィール（GBP）連携仕様（MVP）

最終更新: 2026-02-03

## 目的
MVPで最優先の価値として、**GBPの口コミ（レビュー）を取得し、返信できる**状態を作ります。

## MVPでやること（範囲）
- 店舗単位での **接続/解除**
- GBPロケーションの **紐付け**
- 口コミ（レビュー）の **取得（同期）→DB保存→受信箱表示**
- 口コミへの **返信送信**（履歴保存）
- 連携状態の可視化（最終同期、エラー内容）と **再同期**

## 連携の責務分離（重要）
### フロント（React）
- 「接続する/解除する」ボタン
- 連携状態の表示（最終同期、エラー、ロケーション）
- 受信箱の表示/返信UI

### サーバー（Edge Functions想定）
- OAuth開始/コールバック処理
- トークンの安全な保管（refresh token含む）
- GBP APIの呼び出し（口コミ取得、返信送信）
- 定期同期（cron）・再同期

## トークン取り扱い（絶対ルール）
- OAuthクライアントシークレットやrefresh tokenなどの**秘密情報をクライアントに置かない**。
- DB内に保存する場合も、クライアントからは読めない設計にする。
  - 例: `integration_credentials` テーブルを作成し、RLSで **全ユーザー拒否**。
  - Edge Functions（サービスロール）だけが参照/更新できる。

## 同期仕様（idempotent）
### 取り込みの考え方
- GBP側のユニークID（例: review id）を `external_message_id` として保存し、**二重取り込みを防止**する。
- 同期は「差分で」行い、最終同期時刻（`integrations.last_sync_at`）を更新する。

### エラーの扱い
- 失敗した場合は、`integrations.last_error` に
  - いつ
  - 何が
  - どうすれば直る可能性が高いか（可能なら）
  を保存し、GUIで見えるようにする。

## UI要件（迷わないための表示）
### 連携状態（最低限）
- 接続状態（接続済み/未接続）
- 対象ロケーション（どの店舗に紐づいたか）
- 最終同期（日時）
- 最新エラー（短い説明）

### 操作（最低限）
- 接続する
- 解除する
- 再同期する（ボタン）
