# ユーザー作成・追加ルール（v3.1）

最終更新: 2026-02-15

## 1. 基本ルール
- 新規ユーザー作成時は、**グループ必須 + 店舗必須**です。
- `ADMIN/SUPERVISOR/MANAGER` のみユーザー招待が可能です。
- `USER` は招待不可です。

## 2. 新規ユーザー作成（メールが未登録の場合）
### 実行画面
- `ユーザー管理 > 新規ユーザー作成（招待）`

### 必須入力
1. 名前
2. メールアドレス
3. 権限ロール
4. グループ（既存選択 or 新規作成）
5. 店舗（既存選択 or 新規作成）

### ロール別に作成できる対象
- ADMIN: `ADMIN / SUPERVISOR / MANAGER / USER`
- SUPERVISOR: `MANAGER / USER`
- MANAGER: `USER`

## 3. 既存ユーザー追加（メールが既に登録済みの場合）
### 実行画面
- `ユーザー管理 > 既存ユーザーを追加`

### 手順
1. 追加先のグループを選択
2. 追加先の店舗を選択
3. 既存ユーザーを検索して選択
4. 追加を実行

### 制限
- SUPERVISORは同一管理ユニット内のみ追加可能
- MANAGERは自グループ内の`USER`のみ追加可能

## 4. 既存メールを新規招待した場合
- 新規招待APIは失敗し、以下の固定エラーになります。

`すでに存在しているユーザーのため招待できません。別のメールアドレスを指定してください。`

## 5. 招待URLの運用
- 招待URLは `/invite` に着地します。
- 招待ユーザーは初回パスワード設定完了まで通常画面へ進めません。

## 6. よくある運用ミス
### 店舗未選択で招待したい
- 不可です。必ず店舗を選ぶか作成してください。

### 既存ユーザーを「新規招待」で処理したい
- 不可です。`既存ユーザーを追加` を使用してください。

### MANAGERがMANAGERを作りたい
- 不可です。MANAGERが作成できるのはUSERのみです。
