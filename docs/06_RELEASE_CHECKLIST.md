# TEPPEN MEO：MVP受け入れチェックリスト

最終更新: 2026-02-03

このチェックリストは「MVPが完成したか」をブレなく判断するためのものです。

## 0. 前提（環境）
- [ ] 本番URLがある
- [ ] 本番環境の環境変数が設定されている（`docs/04_ENV_AND_SECRETS.md`）
- [ ] DBマイグレーションが適用されている（再現手順がある）

## 1. 認証（ログイン/招待/リセット）
- [ ] メール/パスワードでログインできる
- [ ] 招待（invite）→初回ログインが通る
- [ ] パスワード再設定（reset）が通る
- [ ] ログアウトでセッションが切れる

## 2. ロール/権限（UIとDBの両方）
- [ ] USERはユーザー管理等の管理機能にアクセスできない（UI）
- [ ] USERが直接APIを叩いても管理操作ができない（DB/RLS）
- [ ] MANAGER/ADMINは許可された範囲で管理操作ができる

## 3. 投稿（作成→一覧→カレンダー→予約）
- [ ] 投稿を作成できる（下書き）
- [ ] 画像/動画をアップロードして投稿に紐づけられる
- [ ] 投稿一覧にDBの投稿が表示される
- [ ] カレンダーにDBの投稿が表示される
- [ ] 予約投稿を作成できる
- [ ] 予約が実行され、成功/失敗が記録される（ログ/履歴）

## 4. 統合受信箱（GBP）
- [ ] 店舗単位でGBP連携を接続できる
- [ ] 口コミを同期して受信箱に表示できる
- [ ] 口コミに返信できる
- [ ] 返信履歴が保存され、返信済みが判別できる

## 5. 監査ログ
- [ ] 投稿の作成/更新/削除が監査ログに残る
- [ ] 連携の接続/解除/同期/返信が監査ログに残る
- [ ] ADMINが監査ログを確認できる

## 6. 本番確認（最低限）
- [ ] 主要導線（ログイン→投稿→受信箱→設定）が迷わず操作できる
- [ ] 失敗時に「次に何をすれば良いか」分かるメッセージが出る
